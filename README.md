# ShoeYakupova2 - Магазин "Чудо Обувь"

Приложение для автоматизации работы обувного магазина. Разработано на платформе WPF (C#) с использованием базы данных SQL Server и технологии Entity Framework.

## Реализованный функционал:
- **Авторизация и роли:** Вход в систему по логину. Разграничение прав доступа (Гость, Авторизованный клиент, Менеджер, Администратор).
- **Каталог товаров:** Вывод списка обуви, поиск, фильтрация по категориям и сортировка по цене/названию.
- **Пагинация:** Вывод товаров порционно (по 10 штук на страницу).
- **Визуальное оповещение:** Подсветка строк красным цветом, если остаток товара на складе менее 5 пар.
- **Корзина:** Добавление товаров с выбором размера и количества, проверка складских остатков, автоматический пересчет суммы.
- **Оформление заказа:** Сохранение заказа в БД с автоматическим списанием товара со склада.
- **Управление заказами (Менеджер/Админ):** Просмотр истории заказов, изменение состава, удаление позиций. Для администратора доступно изменение даты заказа.
- **Аналитика (Админ):** Просмотр статистики продаж за период (общая сумма, количество заказов, ТОП-5 товаров) с возможностью экспорта отчета в PDF.

## Используемые технологии:
- Язык программирования: C#
- Платформа: WPF (.NET Framework 4.7.2)
- База данных: Microsoft SQL Server
- ORM: Entity Framework
- Библиотека для работы с PDF: iTextSharp
